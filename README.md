# Afterglow — Project 2

An interactive digital portfolio / visual-experiment website built with HTML, CSS, JavaScript, and Three.js.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. For the full animated background, keep an internet connection available so the Three.js and font CDNs can load.

## Before publishing
- Replace `example@gmaiil.com;.` in `index.html` with your preferred email address.
- Add your GitHub repository URL to the project report after creating the repository.
- Test the site on both desktop and mobile.

## Features
- Interactive Three.js particle background
- Responsive navigation and page sections
- Four clearly labelled concept-study cards
- About section describing the technologies used
- Contact section with an email link
- Reduced-motion support and a CSS fallback if WebGL is unavailable

## Technologies
HTML5 · CSS3 · JavaScript · Three.js
